# SauceDemo Manual QA Testing Project

## Project Overview

This project demonstrates manual software testing of the SauceDemo e-commerce web application.

The purpose of this project is to practice real-world QA activities including test planning, test case creation, test execution, defect reporting, and documenting test results.

## Application Under Test

**Application:** SauceDemo
**Website:** https://www.saucedemo.com/

## Testing Performed

* Functional Testing
* Smoke Testing
* Regression Testing
* Exploratory Testing
* Positive Testing
* Negative Testing

## Features Tested

* User Login
* Invalid Login
* Product Inventory
* Product Sorting
* Shopping Cart
* Checkout
* Required Field Validation
* Order Completion
* Logout

## QA Deliverables

This project includes:

* Test Summary Report
